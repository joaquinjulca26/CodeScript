# CodeScript

> A modern programming language inspired by Python, C++, Java, and TypeScript.

## 🚀 About

CodeScript is an open-source programming language created by Joaquín Julca.
<img width="1070" height="636" alt="image" src="https://github.com/user-attachments/assets/d3a5c315-f76d-4e71-ab68-1b2670906f82" />


The goal of CodeScript is to provide a modern, simple, and powerful programming language that combines readability with performance.

## ✨ Features

- Modern syntax
- Easy to learn
- Open source
- Inspired by Python, C++, Java, and TypeScript
- Currently under development
