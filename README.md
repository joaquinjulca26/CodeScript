# CodeScript

> A modern programming language inspired by Python, C++, Java, and TypeScript.

## 🚀 About

CodeScript is an open-source programming language created by Joaquín Julca.

<img width="1070" height="636" alt="image" src="https://github.com/user-attachments/assets/d3a5c315-f76d-4e71-ab68-1b2670906f82" />

The goal of CodeScript is to provide a modern, simple, and powerful programming language that combines readability, performance, and developer-friendly syntax.

CodeScript is currently under active development and continues to evolve with new features.

## ✨ Features

* Modern syntax
* Easy to learn
* Open source
* Inspired by Python, C++, Java, and TypeScript
* Variable support with `let`
* Basic output using `Output()`
* Initial support for `If` and `Else`
* Basic interpreter
* Currently under development

### What's New in v0.0.3

- ✅ Added the first implementation of `If`
- ✅ Added the first implementation of `Else`
- ✅ Improved the interpreter structure for future control flow features
- 🚧 Preparing the language for comparison operators and loops

### Example

```cds
let name = "Joaquin"

Output(name)

If(name)

Else
```

Output:

```text
Joaquin
If: the variable 'name' exists.
Else executed.
```
